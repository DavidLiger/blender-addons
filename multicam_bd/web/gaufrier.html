Script Blender (Multi-Cam BD)

A coller dans Scripting > Text Editor puis Run Script. Cree les cameras manquantes (a repositionner) et met a jour res_x / res_y sur les existantes, avec les memes bornes que le bouton "Definir resolution" de l'addon.

Exporter en PNG

PNG a la taille reelle de la page, fond transparent. Les rendus sont decoupes a la forme exacte de chaque case (y compris obliques). Chaque type d'export a son propre nom de fichier - pas d'ecrasement entre eux.
